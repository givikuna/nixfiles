# Security Policy

## Reporting a Vulnerability

If you find a vulnerability here somehow and want to report it.
Please do.

### Private Disclosure (Preferred):

Email me at **gvtsvariani@gmail.com**

## Public Disclosure

If this is safe to show up on GitHub issues, go ahead.
Otherwise, please do **NOT** do that.
Obviously.

## What Constitutes a Security Issue?

Remote code execution
Plaintext secrets
Privilege escalations
Weak permissions
insecure service configs
Outdated packages with known CVEs
Logging leaks
etc...
